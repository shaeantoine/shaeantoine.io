Shae McKenna

I build software and think about the structures underneath it. Most of my time is spent somewhere between machine learning and systems work — the places where abstractions get thin and you have to decide what you actually mean.

Occasionally the thinking becomes writing. Not always long, not always finished, but honest about what I don't yet understand. The things I've built are here — some run in your browser, others only make sense described.

There's a version of me that fits on a single page, and a more tedious one that fits on a CV. I keep a list of what I've been reading, mostly so I can retrace how my thinking changed.

If you'd like to talk, you can find me.
